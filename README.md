# 王朝模拟器

一个按天进行的王朝文字游戏。玩家输入皇帝姓名与开局背景，通过自由文字对话行动。人物具有自主活动与隐藏属性，人物图谱、档案和重要事件纪仅呈现皇帝已经获悉的信息。

## GitHub Pages 浏览器版

在线入口：[王朝模拟器](https://nahc2o4.github.io/DynastyEmulator/)。浏览器版与本地版共用游戏规则、数值结算与 LLM 工具循环，不需要 Node.js 服务端。

进度和模型配置自动写入当前浏览器的 IndexedDB；刷新、关闭页面后重新打开可继续。写入使用事务并保留上一份有效备用存档，损坏时尝试恢复。结算先保存，再等待模型补充叙述；行动回执防止同一请求重复结算。多个页面通过写锁避免同时操作进度。

在「模型设置 → 王朝存档」中导出、导入 JSON 文件，可备份或迁移到其他浏览器。网站存档属于当前浏览器与网站，不会自动同步设备；清除网站数据会删除本机进度。「保护自动存档」可请求浏览器优先保留网站存储。

浏览器直接连接 DeepSeek 或其他兼容平台。API Key 仅保留在当前页面内存，不写入网站存储或导出文件；刷新后需重新填写。兼容平台需要支持浏览器跨域访问（CORS）。固定 `agent.md` 与用户补充指令仍分别传入模型。

隐藏属性保留在浏览器存档中，界面与发送给模型的可见信息不展示这些属性。浏览器版可通过开发者工具或导出文件检查完整存档，不具备服务端的防篡改能力。

构建与本地预览：

```powershell
npm run build:pages
npm run preview:pages
```

预览地址为 `http://127.0.0.1:4174/DynastyEmulator/`。发布包只包含明确列出的界面、规则与浏览器模块，不包含 `data/`、环境变量或服务端文件。GitHub Actions 在 `master` 更新后检查、测试并部署 `dist/` 到 Pages。

## 运行

安装 Node.js 22 或更高版本后，在项目目录运行：

```powershell
npm start
```

打开 `http://127.0.0.1:4173`。项目使用 Node.js 内置模块，无需安装第三方依赖。

## 开始游戏

输入名字，选择建国初期、盛世或乱世。开局只改变国库和待处理事务数量；每场人物的先天属性与个性由程序随机生成。对话框支持直接输入行动，Enter 发送，Shift + Enter 换行。

行动消耗游戏时间，时间用尽或就寝后进入下一天。人物会在流逝的时间内自主行动，公开事件、汇报和调查决定你能够得知什么。皇帝死亡后游戏结束，档案与记录仍可查阅。

查看人物图谱、人物档案和已有事件记录不推进时间。向人物询问新的消息、派人调查、召见等通过游戏对话执行并消耗时间。

可以在游戏中直接输入「添加人物李白」或「召见赵云」。指定姓名不存在时，程序现场生成人物并加入档案；同名人物沿用原有身份和经历。新人物的年龄、隐藏属性与个性由程序随机生成，随后参与日常自主活动与事件。还可写「召见工部尚书张恒」或「添加人物李白，身份为书生」指定公开身份。登记人物和召见属于游戏行动，会消耗时间；之后查阅档案免费。新人物随当前王朝自动存档，刷新和重启后仍保留。

## 模型接入

默认本地规则引擎可用于体验界面和基础行动，不调用外部模型。自由语言的理解与叙事能力取决于所接入的 LLM；本地模式使用有限的文本识别与程序记录。

在模型设置中选择 DeepSeek 或兼容 Chat Completions 的平台，输入接口地址、模型名称与 API Key，然后保存。测试连接读取模型列表；成功访问列表并不等同于完成真实的工具调用验证。

DeepSeek 默认地址 `https://api.deepseek.com`，模型 `deepseek-flash`，依据 [官方接口文档](https://api-docs.deepseek.com/zh-cn/) 和 [工具调用 API](https://api-docs.deepseek.com/api/create-chat-completion/)。本地兼容模型可以使用 localhost 的 HTTP 接口。当前接入方式为 API Key。

本地服务版的 API Key 仅保存在本地服务的内存，不写入存档、浏览器存储或日志；重启服务后重新输入。也可先保存 DeepSeek 配置，再通过 `DEEPSEEK_API_KEY` 环境变量重启服务提供密钥；环境密钥仅用于官方 DeepSeek 地址。

模型连接保留环境代理；只有连接明确被配置的本机代理拒绝时，才尝试一次安全直连。直连仍校验 HTTPS 证书与域名，不跟随接口跳转。Node.js 24.5 或更新版本会自动合并系统信任证书，建议使用 Node.js 24 LTS；较旧版本遇到证书错误时请升级。连接提示会区分超时、证书、DNS、连接拒绝与平台授权错误。

固定游戏设定在 [agent.md](agent.md) 中，由服务端读取为 system 消息。用户补充指令单独追加为 user 消息，可调整叙事偏好，不替换固定规则。

## 计算与信息边界

模型使用 `execute_action` 工具提交行动类型、目标和描述，程序决定成本、耗时、随机结果与状态变化。工具接口不接受模型给出的属性增减、概率或结算值。同一次输入重复调用行动工具只返回已有结算，不重复执行。

查询工具与界面读取仅获取可见视图。隐藏属性、人物私下行为和未公开关系保留在完整存档，LLM 对话上下文不接收这些信息。本地服务版的完整存档只保留在服务端；浏览器版保留在本机 IndexedDB。

界面国库为御前账面记录；未被发现的侵吞不会立即暴露金额，核查账目后才更新已知余额。人物近况同样以最近一次见闻或奏报为准，查看档案不会自动获悉新发生的私下行为。

## 存档与规则

本地服务版进度自动保存在 `data/world.json`，重启本地服务或刷新页面会继续当前王朝。存档包含日期、对话、人物隐藏状态、事件与行动回执；模型配置与补充指令保存在 `data/settings.json`，不含密钥。这些文件不通过网页服务提供，也不进入 Git。

程序结算成功后立即保存，再等待 AI 叙述。如果服务在等待回复时中断，重启后仍保留已结算的进度和程序记录；重试同一行动不会重复扣钱或耗时。写入先使用临时文件并同步到磁盘，再替换主存档；每次写入保留最近一份有效备用存档 `data/world.previous.json`。主存档缺失或损坏时会尝试恢复备用存档并提示，两个文件都无法读取时会报错，不会悄悄重置王朝。

当前采用单个王朝自动续玩。开启新王朝会替换当前进度并留下一份备用存档；备用存档用于异常恢复，后续写入会更新它。自定义存档目录可通过 `DYNASTY_DATA_DIR` 环境变量设置；迁移游戏时应复制整个存档目录。

初版平衡参数集中在 [config/rules.mjs](config/rules.mjs)。这些是暂定的程序规则；人物的具体属性由程序随机产生，后续可以调整事件池、公式和分布。

## 项目结构

```text
public/              游戏界面、样式与浏览器交互
config/rules.mjs     暂定规则、人物背景、事件素材
lib/engine.mjs       权威状态、随机属性、时间、人物行为和结算
lib/agent.mjs        LLM 工具循环与叙事
lib/model.mjs        平台接入、授权与错误处理
lib/model-transport.mjs  系统证书信任与失效本机代理回退
lib/store.mjs        原子存档与备份
agent.md             固定游戏 Agent
server.mjs           本机服务与 API
tests/               规则、模型和服务验证
```
